# Arena de Cartas - Duelo de Magos

Jogo de cartas por turnos em C com Allegro 5, inspirado em card games de arena.
Cartas, imagens e sons são originais. Cada carta jogada exige resolver uma conta
(função exponencial, logarítmica, afim, quadrática, porcentagem, matemática financeira).

## Como rodar

**Windows (Visual Studio):** abra `ArenaCartas.sln`. Veja `COMO_ABRIR_NO_VISUAL_STUDIO.txt`.

## Mais informações

- `LEIA-ME.txt`: regras, como jogar e como trocar as imagens
- `ESTRUTURA_DO_CODIGO.txt`: organização dos arquivos `.c`
